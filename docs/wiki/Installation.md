> **Note:** nepenthe's `pip` / `conda` packages are not yet published. For now,
> build from source (see [Build from Source](Build-from-Source)).

## Pre-requisites

You need Python >=3.10 on your machine to install `nepenthe`.

## Install with `pip` (once published)

```bash
pip install nepenthe
```

## Install with `conda` (once published)

```bash
conda install nepenthe --channel conda-forge
```

## Source installation

For other platforms and for development installations, [build `nepenthe` from source](Build-from-Source).
