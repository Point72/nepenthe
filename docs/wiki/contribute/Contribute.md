> [!NOTE]
>
> `nepenthe` requires [Developer Certificate of Origin](https://en.wikipedia.org/wiki/Developer_Certificate_of_Origin) for all contributions.
> A [Probot GitHub App](https://probot.github.io/apps/dco/) checks that commits include a sign-off.
> Read the [commit sign-off instructions](Local-Development-Setup#configure-commit-signing).

Open an issue on our [issues page](https://github.com/Point72/nepenthe/issues) for **bug reports** and **small feature requests**.

Use our [discussions page](https://github.com/Point72/nepenthe/discussions) for **questions** and **larger changes or features**.

For **contributions**, see the [developer documentation](Local-Development-Setup).
Issues labeled `help wanted` or `good first issue` are starting points.
The [Architecture](Architecture) page describes the crate layout, modules, and
design decisions.

For **documentation updates**, open a PR against `/docs/wiki`. A GitHub workflow
publishes those pages to the wiki and overwrites direct wiki edits.
